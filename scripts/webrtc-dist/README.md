# webrtc-xcframework (TempTalk)

Prebuilt `LiveKitWebRTC.xcframework` used by the TempTalk fork of the
[LiveKit Swift SDK](https://github.com/livekit/client-sdk-swift). Each tag is the WebRTC version;
the zip is attached to the GitHub Release of the same name.

* Built from [webrtc-sdk/webrtc](https://github.com/webrtc-sdk/webrtc) with
  [webrtc-sdk/webrtc-build](https://github.com/webrtc-sdk/webrtc-build).
* The framework is renamed to `LiveKitWebRTC`, and Objective-C symbols are prefixed with `LK`
  (for example `LKRTCPeerConnection`).

This repository is generated by the SDK's release scripts. Do not edit it by hand.

## Usage

```swift
.package(url: "https://github.com/<owner>/webrtc-xcframework.git", exact: "<version>")
```

and depend on the `LiveKitWebRTC` product.

## Private repository

When this repository is private, SwiftPM downloads the zip from the
`api.github.com/.../releases/assets/<id>.zip` URL in `Package.swift`, which needs a token in
`~/.netrc` (Xcode and `xcodebuild` both read it):

```
machine api.github.com
  login <GitHub user>
  password <token with Contents read-only on this repository>
```

`badResponseStatusCode(404)` while resolving means `~/.netrc` is missing or the token cannot read
this repository.
